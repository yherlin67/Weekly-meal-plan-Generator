# Weekly-meal-plan-Generator

## 🚧 En cours de développement 🚧 
Site web manipulant PHP et IA, servant à générer des repas pour la semaine à partir de différentes informations transmises.

- Utilisation de la librairie Php Guzzle pour faciliter la consommation des API en Php.
- Utilisation de la librairie Php Phpdotenv pour charger automatiquement des variables de configuration depuis un fichier .env, qui peut donc rester secret (contient la clé API).

NB : Pour réaliser ce projet, je m'aide du livre "PHP et intelligence artificielle" aux éditions ENI. J'ai pu trouver ce livre à la bibliothèque de l'IUT Robert Schuman et de Pharmacie, à Illkirch-Graffenstaden.
